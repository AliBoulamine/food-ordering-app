# Online Food Ordering Application 🍔🍕

## Objective

This project demonstrates the design, development, and deployment of an Online Food Ordering Application for managing restaurant menus, orders, and user interactions. The objective is to streamline food ordering processes, improve customer experience, and support operational efficiency for restaurants through a responsive web-based interface.

## Problem Statement & Solution

Manual ordering systems can lead to inefficiencies, order inaccuracies, and customer dissatisfaction. Customers expect seamless online interfaces to browse menus and place orders effortlessly from any device.
This application streamlines the ordering process by providing a responsive, interactive experience using HTML, CSS (Tailwind), JavaScript, and AJAX, minimizing manual errors and improving order accuracy.

## Features

- **Admin Login:** Authentication interface with alert validations.
- **Dynamic Menu:** Menu items loaded asynchronously via AJAX (`fetch` API) from a local JSON file.
- **Interactive Cart:** Real-time updating of cart items utilizing JavaScript event handling.
- **Responsive Layout:** Structured with Tailwind CSS (Grid & Flexbox) for a seamless cross-device experience.

## Technologies Used

- HTML5
- Tailwind CSS (via CDN)
- JavaScript (Vanilla, ES6+)
- AJAX (Fetch API)
- Git & GitHub for Version Control

## How to Run

1. Clone this repository to your local machine.
2. Open the project folder in VS Code.
3. Use the **Live Server** extension to open `index.html` (Required to avoid CORS issues when fetching the local JSON file).
4. Enter credentials (`admin@gmail.com`) to login and explore the dynamic menu.
